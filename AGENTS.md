# Contributor guide

This is the portable distribution of an experimental Hermes context-engine plugin. Read README.md and docs/DEVELOPMENT.md before changes; use docs/INSTALL.md for installation and docs/EVALUATION.md before making performance claims.

Keep runtime code, tests, installation, documentation and recovery consistent. Never patch Hermes core or bundle user configuration, credentials, conversation history, archives, personal memory or machine-specific evidence. Test only in isolated synthetic Hermes homes. Do not call paid providers during automated tests.

The package is staged privately for owner review. Do not change repository visibility, publish a release, post on social media or alter a live Hermes installation as part of documentation or package testing.

Preserve native stock fallback, explicit data/spending authorization, per-host/profile scope and persistent accounting. Existing user edits are conflicts, not permission to overwrite. A successful synthetic test does not establish real task quality, savings or compatibility with every Hermes revision.
